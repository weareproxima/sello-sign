# Sello Sign

El firmador de documentos tributarios electrónicos de [Sello](https://sello.tax):
JWS en El Salvador; XMLDSig o XAdES en República Dominicana, Costa Rica, Panamá,
Guatemala, Ecuador, Bolivia, Perú, Colombia, Uruguay y Brasil. Open source
(AGPL-3.0).

En reconstrucción: el API en Go (`apps/api`) y el panel en TanStack Start
(`apps/panel`). Ver [`AGENTS.md`](AGENTS.md) y [`docs/rebuild.md`](docs/rebuild.md).
